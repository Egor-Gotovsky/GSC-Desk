# GSC Desk · первая локальная версия

Личный дашборд Google Search Console для macOS. Интерфейс на русском, Python 3.9+, SQLite, без npm и сторонних Python-пакетов. Сервер слушает только `127.0.0.1`.

## Быстрый запуск

1. Оставьте папку `gsc-desk` целиком в удобном месте.
2. Откройте `Start.command` двойным щелчком в Finder. Откроется Terminal и браузер.
3. Адрес приложения: **http://127.0.0.1:8765**. Используйте именно этот адрес, не `localhost`.
4. До подключения Google можно нажать **«Посмотреть демо»**. Все 36 сайтов `.example` и цифры в демо вымышлены и не записываются в базу.
5. Для своей статистики откройте **«Подключение Google»** и выполните настройку ниже.

Если двойной щелчок не запускает файл, откройте Terminal в папке приложения и выполните:

```sh
python3 app.py
```

В этом окружении уже есть Python 3.9.6. На другом Mac при отсутствии Python установите актуальный Python с [python.org](https://www.python.org/downloads/macos/). Если Python с python.org сообщает об ошибке сертификата, запустите поставляемый с ним `Install Certificates.command`; не отключайте проверку HTTPS.

Окно Terminal должно оставаться открытым. Закрыть вкладку браузера можно — синхронизация продолжится. Остановка сервера: **Ctrl+C** в Terminal. Приложение не устанавливает автозапуск macOS.

## Однократное подключение Google

Приложение использует настоящий OAuth 2.0 для Desktop apps с PKCE, одноразовым `state` и разрешением `webmasters.readonly`. Пароль Google в приложение не вводится.

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте отдельный проект, например `GSC Desk Personal`.
2. В **APIs & Services → Library** найдите **Google Search Console API** и включите его.
3. В **Google Auth Platform** заполните Branding: название приложения, контактный адрес и почту поддержки. Названия разделов могут немного различаться в зависимости от интерфейса Google.
4. В Audience для обычного Gmail выберите **External**. В режиме **Testing** добавьте собственный Google-аккаунт в **Test users**. Для Workspace режим Internal доступен только в подходящей организации.
5. В Data Access добавьте разрешение `https://www.googleapis.com/auth/webmasters.readonly`, если интерфейс просит заранее задать scopes.
6. В **Clients → Create client** выберите тип **Desktop app**. Не Web application. Скачайте JSON клиента.
7. В GSC Desk нажмите **«Подключение Google» → «Загрузить OAuth JSON»**, выберите скачанный файл.
8. Нажмите **«Войти через Google»**, выберите аккаунт с доступом к GSC и разрешите чтение Search Console. Возврат произойдёт на локальный адрес автоматически. Redirect URI для Desktop client вручную не прописывается.
9. Начнётся загрузка всех доступных подтверждённых ресурсов за последние 28 дней, включая сегодня по PT. Новые ресурсы обнаруживаются при каждом обновлении всех сайтов.

### Testing и постоянный доступ

Для External приложения со статусом Testing Google обычно выдаёт refresh token на 7 дней для этого набора разрешений. После истечения потребуется снова войти. Это ограничение Google, а не расписания приложения.

Для постоянного личного использования можно перевести собственное приложение в **Production** в Google Auth Platform. Проверка и предупреждения Google зависят от scopes, аудитории и текущих правил. Публичное распространение и доступ других пользователей могут требовать verification; эта версия рассчитана на личное использование. Не добавляйте лишние разрешения.

Инструкции Google: [Desktop OAuth](https://developers.google.com/identity/protocols/oauth2/native-app), [срок жизни токенов](https://developers.google.com/identity/protocols/oauth2#expiration).

## Что реализовано

- Несколько Google-аккаунтов с переключением в верхней панели и отдельными локальными базами. Существующее подключение сохраняется как «Основной аккаунт». Для нового аккаунта выберите «+ Добавить аккаунт» и пройдите вход Google; OAuth запрашивает чтение GSC и email для различения аккаунтов. Повторное подключение известного Google ID использует прежний профиль.
- Получение всех доступных GSC ресурсов без искусственного ограничения на 300 сайтов. Доменный ресурс и URL-префиксы показываются отдельными карточками.
- Карточки: клики, показы, CTR, средняя позиция и дневные графики; дата последней загрузки именно выбранного диапазона.
- 7, 14, 28, 90 дней и произвольный диапазон в пределах последних 16 месяцев; без сравнения с прошлым годом.
- Веб-поиск, картинки, видео, новости, Discover и Google News.
- Поиск сайта, сортировка по кликам/показам/имени/ошибкам, избранное, несколько групп у одного сайта и отдельные цветные теги. Кнопки «Группы» и «Теги» открывают общий редактор с поиском, массовым выбором доменов и редактированием существующих записей. В карточке сайта можно выбрать несколько групп и тегов; на дашборде есть независимые фильтры.
- Подробный отчёт: запросы, страницы, страны, устройства; фильтры по вхождению запроса/URL и точному коду страны/устройству. Страна — трёхбуквенный код, например `ita`, `usa`, `rus`.
- Таблицы по 50 строк, навигация до 50 000 строк на диапазон. Итоги берутся отдельным запросом, а не суммой видимых запросов.
- Кнопка **«Обновить данные»** для всех сайтов, кнопка в деталях и значок ↻ на отдельной карточке.
- Очередь, прогресс, защита от повторного запуска, ограничение частоты API, повторы при временных HTTP/сетевых ошибках. Ошибки отдельных сайтов не останавливают остальные.
- Локальный кэш, сохранение последней успешной статистики при ошибке обновления.
- Расписание **00:00 и 17:00 Europe/Minsk** с проверкой раз в 20 секунд.

## Как работает обновление

В расписании обновляются последние 28 дней веб-поиска и последний диапазон/тип, для которого вы запускали обновление всех сайтов. Полный повтор последних дней учитывает пересчёты предварительной статистики Google. Старые произвольные диапазоны можно обновлять вручную.

После старта приложения или пробуждения компьютера пропущенное расписание выполняется один раз для последнего наступившего слота. Пока компьютер выключен, спит или приложение закрыто, обновления нет. После неудачной попытки расписание не запускается в бесконечном цикле: ошибки видны в интерфейсе, повторить можно кнопкой или дождаться следующего слота.

Ручное обновление не сдвигает расписание. Одновременно выполняется одна очередь; при уже идущей загрузке приложение сообщает об этом. Если вы выбрали другой диапазон во время загрузки, после её завершения нажмите «Обновить данные» для нового диапазона.

При применении нового диапазона без кэша автоматически запускается его загрузка для всех сайтов. Таблицы запросов/страниц загружаются при открытии сайта и кэшируются на 6 часов. Обновление сайта или всех сайтов очищает соответствующий кэш деталей.

Интернет нужен для Google. Уже сохранённые диапазоны и ранее открытые детали доступны из кэша; для нового диапазона и новых фильтров потребуется загрузка. Не все диапазоны заранее выкачиваются: это экономит квоты и время для 300+ сайтов.

## Особенности данных GSC

- Используется `dataState: all`: последние доступные данные, включая предварительные. Даты считаются в Pacific Time, как в GSC; расписание — в Минске. Это разные часовые пояса.
- Google может публиковать данные с задержкой. Кнопка обновления получает доступное, но не ускоряет обработку на стороне Google.
- Предварительные дни отмечены. Отсутствующие дни не превращаются в искусственный нулевой трафик: на графике оставляется пробел.
- Клики и показы имеют независимые шкалы, что подписано под графиками. Наведение на точки показывает значения.
- CTR = общие клики / общие показы. Средняя позиция взвешивается по показам, а не усредняется арифметически по дням.
- Доменный ресурс и его URL-префикс могут содержать одинаковый трафик. Верхние итоги суммируют выбранные ресурсы, а не уникальные посещения; избегайте перекрывающихся ресурсов с помощью групп/избранного, если нужен итог без повторов.
- Часть запросов Google скрывает, а API отдаёт ограниченный набор строк. Таблицы не гарантируют абсолютно полный список запросов. Сумма строк может отличаться от итогов.
- Discover и Google News не предоставляют поисковые запросы; выбирайте вкладку «Страницы».
- «Индексация» использует импорт CSV из GSC; почасовой отчёт доступен через период «24 часа». URL Inspection, управление Sitemap, сравнения периодов, фильтры Search Appearance и Telegram-уведомления не реализованы.

Документация: [Search Analytics](https://developers.google.com/webmaster-tools/v1/searchanalytics/query), [квоты](https://developers.google.com/webmaster-tools/limits), [особенности выгрузки](https://developers.google.com/webmaster-tools/v1/how-tos/all-your-data).

## Хранение и безопасность

Данные создаются в папке `data/` рядом с приложением:

- `gsc.sqlite3` — статистика, группы, избранное и состояние расписания;
- `oauth.json` — параметры OAuth-клиента;
- `tokens.json` — токены доступа Google.
- `accounts.json` — названия и идентификаторы профилей; токенов здесь нет.
- `accounts/<id>/` — отдельная база, OAuth-конфигурация и токены дополнительного аккаунта. База основного аккаунта остаётся на прежнем месте. Фоновые задачи закреплены за своим аккаунтом; переключение вкладки их не перенаправляет. Планировщик по очереди обновляет подключённые аккаунты.

Папка имеет права `0700`, приватные файлы — `0600`. Токены хранятся локально в JSON, **без дополнительного шифрования**; приложение не использует macOS Keychain в этой версии. Не отправляйте папку `data/` другим людям и не размещайте её в публичных репозиториях. Для резервной копии остановите приложение и скопируйте папку целиком в своё защищённое хранилище.

Сервис доступен только на loopback, проверяет Host, локальную сессию и Origin для изменений, использует PKCE и одноразовый OAuth state. URL обратного вызова с OAuth-кодом не пишется в журнал. Сторонние аналитические скрипты и внешние шрифты отсутствуют.

«Отключить аккаунт» удаляет локальные токены, сохраняя статистику. Для полного отзыва разрешения используйте [подключения Google-аккаунта](https://myaccount.google.com/connections).

## Проверки и ограничения первой поставки

Автоматические проверки запускаются без подключения Google:

```sh
python3 -m unittest discover -s tests -v
```

Проверены расчёты CTR/позиции, даты, расписание, очередь на 350 синтетических ресурсах, изоляция ошибок, отсутствие дублирующих синхронизаций, кэш, сохранение старых данных при ошибках, фильтры/пагинация и обновление токенов с подменой ответов Google. Интерфейс проверен в локальном браузере.

Подключение основного аккаунта и реальные отчёты проверены. Добавление и повторное подключение аккаунтов проверены автоматическими тестами с подменой ответов OAuth; для проверки второго реального аккаунта нужен вход пользователя в Google. Интерфейс, изоляция профилей и сохранение групп/тегов проверены на двух отдельных тестовых профилях.

## Структура

- `app.py` — HTTP-сервер, Google OAuth/API, SQLite и планировщик;
- `static/index.html`, `static/style.css`, `static/app.js` — интерфейс;
- `tests/test_app.py` — автономные тесты;
- `Start.command` — запуск на Mac;
- `data/` — только ваши локальные данные, не включены в архив поставки.

Для другого порта: `python3 app.py --port 8766`. Для запуска без открытия браузера: `python3 app.py --no-browser`. Папку данных можно указать переменной окружения `GSC_DESK_DATA`.
