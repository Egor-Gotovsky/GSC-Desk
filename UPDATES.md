# Обновление аналитики

## 13 ноября 2026: организация портфеля и аккаунты

- Домен может находиться в нескольких группах. Старые группы мигрируются один раз, без удаления статистики.
- Цветные теги независимы от групп. Они видны на превью и внутри карточки, доступны в отдельном фильтре. Общий редактор групп и тегов позволяет искать сайты, вставлять список доменов, менять название/цвет и состав.
- Несколько Google-аккаунтов: выбор в шапке, добавление через Google OAuth. Данные, настройки, расписание, группы и теги разделены по аккаунтам. События и сохранённые фильтры в браузере также разделены; тема общая.
- «Индексация» импортирует CSV графика GSC с сопоставлением колонок. Нужна выгрузка для выбранного ресурса без фильтров («Все известные страницы»). Для каждого сайта показывается последняя дата отчёта, проиндексировано, не проиндексировано, сумма и доля. Нулевые значения отличаются от отсутствующего отчёта. Дата импорта не подменяет дату отчёта. Сумма — известные Google страницы, а не размер сайта. Автоматической сводки индексации в API GSC нет; устаревшее поле sitemap indexed не используется.
- «Зацепы» анализируют веб-поиск. При синхронизации сохраняются полные дневные наблюдения; первая положительная дата и запросы доступны на отдельной странице. Кнопка «Загрузить историю и запросы» проверяет до 16 месяцев истории для всех сайтов аккаунта. «Новый при наблюдении» требует непрерывных нулевых дней с начала наблюдения в сервисе до первого положительного дня. Первое событие в исторических данных не считается доказанным первым показом за всё время. Дата подключения к GSC не предоставляется API. Неполные и последние три календарных дня исключаются; API может скрывать запросы. Запросы загружаются с пагинацией до 50 000 строк, в развёрнутом списке показываются первые 500.
- Проверки: 27 автоматических тестов, интерфейс проверен в браузере на тестовых аккаунтах. Реальный вход во второй Google-аккаунт выполняет пользователь.

- Периоды «24 часа» (почасовой API Google) и «3 дня» доступны на дашборде и независимо в карточке сайта. Три дня включают сегодняшний день PT. 24 часа — 24 часовых интервала, включая текущий неполный час. Свежие данные предварительные.
- На графиках есть всплывающие значения, вертикальная линия и отметки выбранных метрик. Можно использовать стрелки клавиатуры после фокусировки графика.
- Список сайтов фильтрует портфель; переключатель «Карточки / Список» меняет представление.
- «Проблемы портфеля» фильтруются по типу проблемы, важности, статусу просмотра, сайту и группе. Пороги алертов сохраняются локально.
- Алерты сравнивают последние 7 дней с недельным средним предыдущих 14 дней. Последние три календарных дня исключаются, а явно неполные данные не используются. Нужна полная история всех 21 дней; кнопка «Обновить историю» загружает 31 день. Ошибки синхронизации и давность обновления проверяются независимо от наличия истории. Сигналы доступны внутри приложения; отправка в Telegram не добавлялась.
- «Возможности» — отдельная страница. Кнопка «Обновить анализ» запускает фоновую загрузку всех активных сайтов с двумя рабочими потоками. Результаты сохраняются в SQLite. Запросы отбираются по позициям 4–15; пороги показов и CTR задаются в интерфейсе. Страницы сравниваются за последние 28 полных дней с предыдущими 28; последние три календарных дня исключаются. Отсутствующая строка API не трактуется как нулевой трафик. Google ограничивает детализацию; загружается максимум 50 000 строк каждого отчёта.

Google OAuth и существующая база сохраняются при обновлении приложения. После перезапуска достаточно обновить страницу браузера.

Техническая проверка: `python3 -m unittest discover -s tests -v` (27 тестов).
Документация почасового API: https://developers.google.com/webmaster-tools/v1/searchanalytics/query
